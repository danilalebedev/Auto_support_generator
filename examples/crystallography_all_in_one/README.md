# All-in-one SI example with eight X-ray structures

## Запуск в программе

1. В Generate выберите **Single all-in-one DOCX**.
2. В **All-in-one input** загрузите `All_in_one_input.docx`.
3. В **Spectra source** выберите `Spectra_source.zip`.
4. В **CIF source** выберите папку `CIF_source`.
5. Укажите папку результата и нажмите **Generate SI**. `Crystallography_template.docx` уже встроен в all-in-one секцией `[AUTO SI: CRYSTALLOGRAPHY TEMPLATE]`; отдельное поле можно использовать как внешний шаблон только для файлов без этой секции.
6. Расчёт загрузок включать не нужно: экспериментальные количества уже приведены в столбце Preparation.

`Reference_output.docx` содержит результат реального контрольного запуска. Полная локальная папка запуска с manifest, обработанными `.mnova`, PNG, исходными данными и отчётами может быть воспроизведена этой же командой; сохраняйте её целиком для Add, Patch и Check.

## Что включено

Соединения **3c, 3e, 3f, 3g, 3h, 3i, 3s, 3v** из авторского `Supporting_inf+ACHT.docx`. Для каждого сохранены OLE-структура, название, экспериментальные массы и количества реагентов, растворитель, выход, внешний вид, температура плавления, Rf, HRMS, IR, соответствующие CIF и оригинальный ORTEP. Элементный анализ приведён только там, где он был в источнике.

- Основной архив содержит 16 raw-экспериментов: 1H и 13C для каждого соединения.
- Для 3v основной набор относится к **смеси диастереомеров A:B = 59:41**, а CIF и ORTEP к **минорному диастереомеру B**. Эти данные нельзя трактовать как характеристику одного чистого изомера.
- `Additional_spectra.zip` сохраняет исходный 19F для 3h и отдельные 1H/13C минорного диастереомера 3v. Они не входят в автоматическое 1H/13C-приложение этого примера; текст их описания сохранён в Extra NMR.
- Сохранены дополнительная порция 4a для 3i и граммовый синтез 3e. Методики A/B/D приведены в Preparation для каждого соединения, чтобы полученный SI был самодостаточным.
- В HRMS используется отдельный столбец **HRMS adduct**: для 3g это `[M+Na]+`, для 3v `[M+NH4]+`, для остальных `[M+H]+`.
- Номера CCDC и соответствие файлов документированы в `provenance.json`. Старые имена папок CIF местами не совпадают с финальными номерами соединений; здесь сопоставление сделано по исходному SI, формуле и номеру CCDC. Дубли из `deposit/all.cif` повторно не включены.

## Загрузки и ограничения источника

Экспериментальные загрузки перенесены **из авторского текста**, а не восстановлены из округлённых mmol. Здесь нет единой Reaction schema: используются разные методики, дополнительное внесение реагента и два масштаба реакции. Этот пример показывает сохранение опубликованных экспериментальных количеств, а не новый расчёт загрузок.

Авторские формулировки не исправлены химически без подтверждения. В частности, для 3s в источнике указан `cyclopropane 1c`, а в общей методике D упоминается `4f`, тогда как в описании получения 3v указан `4g`. Эти места необходимо проверить перед публикацией.

Общая симметрия 13C оценивается по молекулярному графу для всех атомов углерода, а не только ароматических. Это не прогноз химических сдвигов: оценка не описывает все диастереотопные окружения, динамический обмен и смеси. Поэтому предупреждения для смеси 3v нельзя устранять уменьшением ожидаемого числа сигналов. Автоматические интегралы и peak picking также требуют проверки химиком.

## Оформление РСА

Над таблицами стоят последовательные подписи **Table S1, Table S2, ...**. Столбцы и таблица центрированы, оставлены только верхняя и нижняя линии. Первая строка содержит CCDC, индексы в брутто-формуле оформлены подстрочно. Add и Patch обновляют номера таблиц после изменения состава или порядка соединений.

В проверенных правилах [JOC](https://researcher-resources.acs.org/publish/author_guidelines?coden=joceah) и [Crystal Growth & Design](https://researcher-resources.acs.org/publish/author_guidelines?coden=cgdefu) требуется понятный заголовок и простая читаемая таблица, но не задано обязательное горизонтальное выравнивание ячеек. Здесь выбран стиль авторского образца. Это не означает автоматическое одобрение SI журналом.

Поставляемые checkCIF PDF импортированы без изменения. Для 3v текстовый checkCIF не предоставлен. Локальные проверки не заменяют официальный checkCIF, депонирование и ответы на alerts.

## Reproduce

The compound table has a landscape section for readability; the embedded SI template produces portrait pages. Source files are not modified by the builder.

```powershell
.venv\Scripts\python.exe -m si_generator `
  --all-in-one-input examples/crystallography_all_in_one/All_in_one_input.docx `
  --spectra-source examples/crystallography_all_in_one/Spectra_source.zip `
  --cif-source examples/crystallography_all_in_one/CIF_source `
  --output output/crystallography_all_in_one/support_information.docx `
  --insert-chemdraw --calculate-elemental-analysis
```
